# SharedVarFinder

Shared variable detection and SIM_FLUSH instrumentation tool for C/C++ source files.
Uses Clang AST JSON dump for accurate shared-variable detection, with source-level
fallback for cases where Clang cannot resolve types (missing headers).

## Features

- Scan directories recursively for shared (global/static) variables
- Instrument shared variable accesses with `SIM_FLUSH` / `SIM_FLUSH_TEMP` calls
- Cacheline-aware merging of adjacent member accesses
- Automatic if/else-if chain instrumentation (`--post-if-flush`)
- Conservative pointer mode: treat all pointer params as potential shared variables
- Bit-field bypass: skip members that cannot take address in C
- Source-level fallback for unresolvable types (`--temp-flush`)

## Install

```bash
python3 -m pip install -e .
```

Requires `clang` on PATH for AST-based detection.

## Quick Start

```bash
# 1. Collect struct definitions for better type resolution
python3 src/sharedvarfinder/collect.py srcFile --all -o srcFile/all_structs.txt
# Outputs: all_structs.txt, all_structs.h, all_structs_bitfield.json

# 2. Instrument a source file
PYTHONPATH=src python3 -m sharedvarfinder.cli --instrument srcFile/example.c \
    -I srcFile \
    --conservative-ptr \
    --post-if-flush \
    --bitfield-map srcFile/all_structs_bitfield.json \
    --struct-header srcFile/all_structs.h \
    --temp-flush
```

## CLI Parameters

### Basic

| Flag | Description |
|------|-------------|
| `paths` | Files or directories to scan (required) |
| `-r, --recursive` | Recursively scan directories |
| `--json` | Output shared variable list as JSON |

### Instrumentation

| Flag | Description |
|------|-------------|
| `--instrument` | Enable code instrumentation mode (requires exactly one file path). Output written to `<name>_result.<ext>` |
| `-I, --include` | Add include directory for Clang AST parsing (repeatable) |

### Shared Variable Detection

| Flag | Description |
|------|-------------|
| `--conservative-ptr` | Treat ALL pointer-typed function parameters as potential shared variables. Enables instrumentation of `ptr->member`, `*ptr`, and `ptr[index]` dereferences |
| `--bitfield-map <path>` | JSON file mapping struct→member→is_bitfield. Bit-field members are skipped (cannot take address in C). Generated by `collect.py` |

### Flush Placement

| Flag | Description |
|------|-------------|
| `--post-if-flush` | Place condition SIM_FLUSH after the entire if/else-if/else chain (not inside the body). Only moves the condition flush, not body flushes |

### Type Resolution

| Flag | Description |
|------|-------------|
| `--struct-header <path>` | Consolidated struct header (`-include`'d during Clang parsing) for better type resolution. Generated by `collect.py --output-header` |

### Source-Level Fallback

| Flag | Description |
|------|-------------|
| `--temp-flush` | Enable source-level regex scan for shared variable member accesses missed by Clang (unresolvable types). Uses `SIM_FLUSH_TEMP` instead of `SIM_FLUSH`. Detects member reads (`ptr->field`) and writes (`ptr->field =`, `ptr->field |=`, etc.) |

## SIM_FLUSH vs SIM_FLUSH_TEMP

- **SIM_FLUSH**: Generated from Clang AST-detected accesses. Reliable, type-aware.
- **SIM_FLUSH_TEMP**: Generated from source-level regex fallback (requires `--temp-flush`). Used when Clang drops AST nodes due to unresolvable types (missing headers). Both macros have identical behavior; the naming distinguishes detection method for debugging.

## collect.py — Struct Collection

```bash
python3 src/sharedvarfinder/collect.py <folder> --all -o <output_prefix>
```

Outputs three files:
- `<prefix>.txt` — struct definitions as text
- `<prefix>.h` — merged header for `--struct-header`
- `<prefix>_bitfield.json` — bit-field map for `--bitfield-map`

## Notes

The current implementation uses a conservative source-level scanner and will report top-level shared variables in most C/C++ files.
If `pylibtooling` is available, the project can be extended to perform deeper AST-based analysis.
